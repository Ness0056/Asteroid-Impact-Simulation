# Asteroid Impact Simulation

A rigid-body dynamics simulation modeling the motion of asteroid
**4179 Toutatis** following a meteorite impact.

The project combines numerical calculations in Python with POV-Ray
visualization to simulate the asteroid's translational and rotational
motion after the collision.

## Overview

The post-impact motion is calculated using conservation of linear and
angular momentum.

The impact produces both:

- Translational motion of the asteroid's center of mass
- Rotational motion caused by the impact's angular momentum

A time-dependent homogeneous transformation matrix is generated and
used by POV-Ray to render the asteroid's position and orientation over
successive frames.

## Physics

The total linear momentum generated by the meteorite is calculated as:

```python
P = m_met * v
```

The angular momentum generated by the off-center impact is:

```python
L0 = np.cross(r, P)
```

The velocity of the combined center of mass is then:

```python
VCM = P / M
```

The asteroid's angular velocity is determined from its inertia tensor:

```python
w = np.linalg.inv(I) @ (R.T @ L0)
```

The rotation matrix is updated iteratively to simulate the asteroid's
orientation over time.

## Rendering

For every simulation step, Python writes the current transformation to:

```text
transforma.dat
```

POV-Ray reads this matrix and applies it to the asteroid model:

```pov
#fopen U10 "transforma.dat" read
```

The resulting frames are rendered sequentially to produce the final
animation.
